
# ✝ Nun'But Blood

Chance based game where each crusade's outcome is determined by the stats of you party members.

## Requirements
Java JDK 21 or Higher (25 preferred)
Gradlew version 9.2.0 +


## Cloning into IntelliJ

2. From intellij's built in version source control, go File → New → Project from Version Control.
3. Paste the repository URL and choose a local directory, then hit CLONE
4. After some time the project will be processed by Gradle and will import all necessary dependencies
5. After a Complete build, type "./gradlew run" in the console to run the application (gradlew.bat run if on windows)



## How To Run Tests

1. Run in the console ./gradlew test
2. Navigate to build/reports/tests/coverage/index.html, for a full test coverage report


## How To Create Jar
1. Run ./gradlew jar in the terminal to generate a jar file
2. Navigate to `build/libs/` in your terminal
3. run java -jar "name_of_saved_jar"
